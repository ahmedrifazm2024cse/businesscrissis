# Market Intelligence Agent Frontend

Modern React dashboard built with Vite, TypeScript, and Tailwind CSS. Connects to the FastAPI analytics API to visualize risk heatmaps, demand predictions, and competitor updates.

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation & Run

1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
   The dashboard will be available at `http://localhost:5173`.
